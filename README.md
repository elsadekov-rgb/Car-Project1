Каталог запчастей автомобиля

Desktop-приложение для удобного поиска, учета и управления автомобильными запчастями.

Программа разработана в рамках курсовой работы

Основные возможности

- Добавление, редактирование и удаление запчастей
- Загрузка и отображение изображений запчастей
- Справочник марок и моделей автомобилей
- Фильтрация запчастей по марке автомобиля
- Поиск по артикулу и названию
- Отдельный столбец **"Марка"** в таблице
- Экспорт данных в Excel
- Удобный и интуитивный интерфейс на PyQt6

Технологии

- **Python 3.10+**
- **PyQt6** — графический интерфейс
- **SQLAlchemy** + **SQLite** — работа с базой данных
- **Pandas + openpyxl** — экспорт в Excel
- **Pillow** — обработка изображений

Установка и запуск
Установка и запуск

1. Склонируйте репозиторий:
   ```
   git clone https://github.com/ваш-username/auto-parts-catalog.git
   cd auto-parts-catalog
   python -m venv venv
   venv\Scripts\activate
   pip install pyqt6 sqlalchemy pillow pandas openpyxl
   python main.py
   или же 
   run.bat
   auto_parts_catalog/
   ```
